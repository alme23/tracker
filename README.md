# Tracker: Agent-Server Metrics Collector

Высокопроизводительная и безопасная клиент-серверная архитектура на языке Go для одноразовой легковесной передачи метрик с целевых хостов (агентов) на центральный сервер.

## 🚀 Ключевые особенности

* **Бинарный протокол (GOB):** Вместо избыточного текстового JSON используется встроенный бинарный кодировщик Go (`encoding/gob`), уменьшающий размер заголовков и нативных типов данных.
* **Максимальное сжатие:** Данные дополнительно компрессируются «на лету» с помощью алгоритма `gzip` перед отправкой по сети.
* **Безопасность без сертификатов:** Трафик защищен симметричным шифрованием **AES-256-GCM** (аутентифицированное шифрование). Архитектура не требует покупки, обновления и проверки постоянных SSL/TLS сертификатов (защита от инфраструктурных сбоев CA).
* **Одноразовые сессии:** Агент осуществляет атомарное подключение (Raw TCP), мгновенно передает зашифрованный пакет и сразу завершает работу, не удерживая постоянное соединение.

## 🛠 Спецификация безопасности

Для обеспечения конфиденциальности и целостности данных используется режим **AES-GCM (Galois/Counter Mode)**.
1. **Криптостойкость:** Ключ шифрования имеет длину 256 бит (32 байта).
2. **Защита от повторов (Replay Attacks):** Для каждого отправляемого пакета генерируется уникальный криптографический случайный вектор инициализации (`nonce`) размером 12 байт.
3. **Аутентификация данных:** Алгоритм GCM вычисляет тег аутентификации. Если злоумышленник попытается модифицировать байты в канале связи, сервер отклонит пакет на этапе дешифрования.

## 💻 Быстрый старт

### 1. Требования
* Установленный Go версии **1.21** или выше.

### 2. Сборка приложений
Из корневой директории проекта выполните сборку бинарных файлов:

```bash
# Сборка Сервера
go build -o bin/server cmd/server/main.go

# Сборка Агента
go build -o bin/agent cmd/agent/main.go
```

### 3. Запуск
Сначала запустите принимающий сервер:
```bash
./bin/server
```
*Вы увидите лог: `Сервер tracker запущен на порту :9000...`*

В другом окне терминала (или на удаленном хосте) запустите агента для отправки метрики:
```bash
./bin/agent
```
*Агент соберет данные, зашифрует их, отправит на сервер и завершит сессию.*

## 📋 Формат передаваемых данных

Архитектура позволяет легко расширять метрики в файле `internal/protocol/packet.go`:

```go
type DataPacket struct {
    Hostname string  `gob:"hostname"`
    OS       string  `gob:"os"`
    CPUUsage float64 `gob:"cpu_usage"`
    RAMTotal uint64  `gob:"ram_total"`
    RAMFree  uint64  `gob:"ram_free"`
}
```

## 🔒 Дисклеймер безопасности (Памятка для Production)
В текущей реализации симметричный ключ `SymmetricKey` захардкожен в файле `internal/crypto/crypto.go`. Перед развертыванием в реальной среде (Production) рекомендуется:
1. Выносить ключ в переменные окружения (`os.Getenv`).
2. Использовать обфускацию строк при компиляции агента под Windows/Linux для предотвращения извлечения ключа методом reverse-engineering.
